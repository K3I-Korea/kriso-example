# 2강 React × Lit 상태 연동 — 실습 자료

슬라이드: 「2강 React × Lit 상태 연동」
1강과 같은 프로젝트(k3i-ds)입니다. 1강 자료를 이미 받았다면 그대로 써도 됩니다.

## 실행
```bash
cd k3i-ds
npm install
npm run dev        # http://localhost:5173/demo/react.html  ← 2강 실습 화면
```
