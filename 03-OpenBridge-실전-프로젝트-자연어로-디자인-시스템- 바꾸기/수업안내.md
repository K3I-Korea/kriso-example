# 3강 OpenBridge 실전 프로젝트 — 실습 자료

슬라이드: 「3강 OpenBridge 실전 프로젝트 — 자연어로 디자인 시스템 바꾸기」
1·2강과 다른 별도 프로젝트입니다.

## 실행
```bash
cd k3i-openbridge-lab
npm install
npm run dev        # 검사 → 토큰 빌드 → http://localhost:5173
```
