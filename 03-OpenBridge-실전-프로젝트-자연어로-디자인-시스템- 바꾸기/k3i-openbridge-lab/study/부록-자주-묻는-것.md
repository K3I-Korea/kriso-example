# 부록 — 자주 묻는 것

3강을 따라 하다 자주 나오는 물음을 모았다.

## OpenBridge 가 무엇인가

OpenBridge(오픈브리지)는 **선박 선교·원격운항 화면을 위한 공개 HMI(Human-Machine Interface, 사람-기계 접점) 디자인 시스템**이다(openbridge.no). 나침반·타각계·수치 표시 같은 **계기(Instrument)**, 버튼·토글 같은 **프리미티브(Primitive)**, 그리고 주간·황혼·야간 팔레트를 묶어 제공한다. 여러 제조사의 선교 장비 화면이 같은 모양·같은 규칙으로 보이게 하려는 것이다.

이 프로젝트는 그 OpenBridge 를 **맨 아래 층(L0)**에 두고, 그 위에 K3I 디자인 시스템(패널·레이아웃)을 얹는다. OpenBridge 는 `@oicl/` 로 시작하는 두 패키지로 들어온다(`package.json`).

- `@oicl/openbridge-webcomponents` — 웹 컴포넌트(`obc-readout`·`obc-compass`·`obc-rudder` 등). 어느 프레임워크에서나 쓰는 태그다.
- `@oicl/openbridge-webcomponents-react` — 그 컴포넌트의 React 래퍼.

**OpenBridge 원본은 고치지 않는다.** 조합하고 감싸기만 한다(`node_modules/@oicl/*` 수정 금지). 계기 하나하나를 다시 만들지 않고 가져다 쓰는 것이 이 실습의 핵심이다.

## "선언(JSON)이 진실 공급원" 이라는 게 무슨 뜻인가

바뀔 수 있는 것(색·상태 규칙·신호·레이아웃·화면 구성)을 전부 `design/*.json` 선언에 두고, **코드는 그 선언을 읽기만 한다**는 뜻이다. 그래서:

- 디자인을 바꾸는 일 = JSON 편집이 된다. 자연어 요청이 대개 코드 수정 없이 끝난다.
- 틀린 편집은 검사기(`npm run check`)가 막는다(06장).
- 같은 규칙이 코드 곳곳에 흩어지지 않아, 한 곳만 바꾸면 모든 화면이 따라온다.

그래서 디자이너가 Figma 에서 바꿨더라도 코드에 바로 넣지 않고, 먼저 JSON 을 고쳐 검사를 통과시킨 뒤 Figma 로 맞춘다(07장). 양쪽을 동시에 진실로 두면 어느 쪽이 맞는지 알 수 없다.

## 토큰이 "OpenBridge 변수의 alias" 라는 게 무슨 말인가

`design/tokens.json` 을 보면 색 토큰이 실제 색(`#hex`)이 아니라 OpenBridge 변수를 가리킨다.

```json
"color": {
  "surface": { "ob": "--container-background-color" },
  "alarm":   { "ob": "--alert-alarm-color" }
}
```

- `ob` 필드가 **OpenBridge 가 정한 CSS 변수 이름**이다. K3I 의 `--k3i-color-surface` 는 그 OpenBridge 변수를 **가리키기만(alias)** 한다.
- 그래서 OpenBridge 팔레트(주간·야간 등)가 바뀌면 K3I 패널 색도 함께 바뀐다. 색을 K3I 가 따로 정하지 않고 OpenBridge 를 따라가게 한 것이다.
- 직접 `#hex` 를 쓰는 것은 **OpenBridge 에 대응 변수가 없을 때만** 허용한다(예: `manual` 은 전용 변수가 없어 강조색을 쓴다).

어떤 OpenBridge 변수가 있는지는 `npm run ob:vars -- <접두어>` 로 찾아본다(06장).

## 상태 6종은 어디서 정해지나

`normal`·`degraded`·`stale`·`invalid`·`alarm`·`manual` 여섯 상태는 **데이터 계층(`src/domain/signal.ts`)에서 결정**되어 패널로 내려간다. 패널은 받은 상태를 그리기만 한다(04장).

- 지금 성립하는 상태 후보를 `Signal.candidates()` 가 모으고, `states.json` 의 `priority` 순서로 하나만 고른다.
- 그 상태의 색(`token`)·형태(`shape`)·문구(`text`)는 `states.json` 이 정한다. 그래서 "manual 을 stale 보다 먼저" 같은 요청이 `states.json` 의 `priority` 수정 하나로 끝난다.

## 왜 `obc-readout` 같은 태그는 `obc-` 로 시작하나

`obc-` 는 OpenBridge 컴포넌트의 접두사다(K3I 것은 `k3i-`). 붙임표가 든 이름이라 기본 HTML 태그와 겹치지 않는다(1강 03장의 커스텀 엘리먼트 작명 규칙과 같다). `k3i-value-panel` 이 OpenBridge 의 `obc-readout` 을 본문에 품는 식으로, 두 디자인 시스템의 컴포넌트가 한 화면에서 함께 산다.
