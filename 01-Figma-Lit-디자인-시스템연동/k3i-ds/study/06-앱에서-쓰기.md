# 06. 앱에서 쓰기 — 순수 HTML · React · Vue

같은 컴포넌트를 세 가지 앱에서 쓴다. 컴포넌트는 하나뿐이고, 프레임워크마다 그걸 부르는 방법만 조금 다르다. 먼저 배포용 파일을 만든 뒤, 각 앱에서 쓰는 코드를 본다.

## 6-1. 배포용 파일 만들기 — npm run build

```bash
npm run build
```

이 명령은 토큰을 다시 만들고, 라이브러리와 타입을 `dist/` 에 낸다.

| 산출물 | 무엇인가 |
|---|---|
| `dist/index.js` | `<ds-*>` 컴포넌트 전부 (순수 HTML·Vue 에서 불러 씀) |
| `dist/react.js` | React 래퍼 |
| `dist/tokens.css` | CSS 변수(라이트+다크) |
| `dist/types/` | 타입 정의 |

`package.json` 의 `exports` 가 이 산출물을 이름으로 연결해 둔다. 그래서 앱에서는 `@k3i/ds`, `@k3i/ds/react`, `@k3i/ds/tokens.css` 로 불러 쓴다.

## 6-2. 순수 HTML / 서버 템플릿

토큰 CSS 를 불러오고, 컴포넌트를 등록한 뒤 태그를 쓴다. 그게 전부다.

```html
<link rel="stylesheet" href="node_modules/@k3i/ds/dist/tokens.css" />
<script type="module">import "@k3i/ds";</script>

<ds-button variant="primary">저장</ds-button>
```

Vue·Angular·Svelte 도 태그는 이대로 쓴다.

## 6-3. React

React 18 이하에서는 커스텀 이벤트와 객체 props 전달이 온전하지 않다. 그래서 얇은 래퍼를 둔다. `src/react/index.ts` 가 `@lit/react` 의 `createComponent` 로 각 컴포넌트를 React 컴포넌트로 감싸고, 커스텀 이벤트를 `onDsInput`·`onDsChange` 같은 React 식 이름으로 바꿔 준다.

```ts
export const Input = createComponent({
  tagName: "ds-input",
  elementClass: DsInput,
  react: React,
  events: {
    onDsInput: "ds-input" as EventName<CustomEvent<{ value: string }>>,
    onDsChange: "ds-change" as EventName<CustomEvent<{ value: string }>>,
  },
});
```

앱에서 쓰는 모습은 `examples/react/SignupForm.tsx` 에 있다.

```tsx
import "@k3i/ds/tokens.css";
import { Button, Card, Input } from "@k3i/ds/react";

<Card elevated>
  <h2 slot="header">회원가입</h2>
  <form onSubmit={...}>
    <Input name="email" type="email" label="이메일" required
           value={email} onDsInput={(e) => setEmail(e.detail.value)} />
    <Button type="submit" variant="primary" fullWidth>가입</Button>
  </form>
</Card>
```

React 19 이상이라면 래퍼 없이 `<ds-button onClick={save}>` 처럼 태그를 직접 써도 된다. 다만 타입 지원과 `onDsChange` 같은 이벤트 이름 때문에 래퍼를 쓰는 편이 편하다.

## 6-4. Vue

Vue 는 `ds-` 로 시작하는 태그를 커스텀 엘리먼트로 알려 줘야 한다. `vite.config.ts` 에 아래를 둔다.

```ts
vue({ template: { compilerOptions: { isCustomElement: (tag) => tag.startsWith("ds-") } } })
```

그러면 태그를 그대로 쓰고, 커스텀 이벤트는 `@ds-input` 으로 받는다. `examples/vue/SignupForm.vue` 를 본다.

```vue
<script setup lang="ts">
import "@k3i/ds";
import "@k3i/ds/tokens.css";
import { ref } from "vue";
const email = ref("");
</script>

<template>
  <ds-input name="email" type="email" label="이메일" required
            :value="email" @ds-input="email = $event.detail.value" />
  <ds-button type="submit" full-width>가입</ds-button>
</template>
```

## 6-5. 핵심 — 왜 한 번만 만들면 되나

세 앱이 같은 컴포넌트 하나(`dist/index.js`)와 같은 토큰 하나(`dist/tokens.css`)를 쓴다. 디자인을 바꾸려면 토큰이나 컴포넌트만 고치면 되고, React·Vue·HTML 쪽 코드는 그대로 둔다. 이것이 "한 번만 구현해서 어디서나 쓴다"의 실제 모습이다.

## 이 장에서 한 것

- `npm run build` 로 배포용 `dist/` 를 만들고 `exports` 연결을 봤다.
- 순수 HTML·React·Vue 에서 같은 컴포넌트를 쓰는 코드를 읽었다.
- React 래퍼가 커스텀 이벤트 이름을 바꿔 주는 까닭을 봤다.
