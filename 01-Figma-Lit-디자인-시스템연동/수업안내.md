# 1강 Figma × Lit 디자인 시스템 — 실습 자료

슬라이드: 「1강 Figma × Lit 디자인 시스템 연동」
2강과 같은 프로젝트(k3i-ds)입니다. 이 폴더만 있으면 1강을 다 할 수 있습니다.

## 실행
```bash
cd k3i-ds
npm install
npm run dev        # http://localhost:5173  ← 1강 실습 화면(index.html)
```

## 따라 하는 교재
`k3i-ds/study/` 에 Figma 연결부터 단계별로 따라 하는 교재가 있습니다. `00` 부터 순서대로 읽으세요.

| 장 | 내용 |
|---|---|
| 00 | 준비와 실습 1 (테마 전환·전역 CSS 공격·폼) |
| 01 | Claude Code ↔ Figma MCP 연결 |
| 02 | 토큰을 코드와 Figma 로 양방향 잇기 |
| 03 | Lit 컴포넌트 뜯어보기 |
| 04 | Figma 에 Component Set 그리기 |
| 05 | Code Connect |
| 06 | React·Vue·순수 HTML 에서 쓰기 |
| 07 | 동기화 정리와 마무리 |

## 이번 시간에 쓰는 파일
| 파일 | 주제 |
|---|---|
| tokens/tokens.json, tokens/themes/dark.json | 디자인 토큰, 다크 테마 |
| scripts/build-tokens.mjs (npm run tokens) | 토큰 → tokens.css 빌드 |
| src/components/ds-button.ts 외 | Lit 컴포넌트, Shadow DOM 격리 |
| src/styles/shared.ts | 공통 기본 스타일, 포커스 링 |
| index.html | 실습 1 — 테마 전환, 전역 CSS 공격, 폼 연동 |
| figma/SETUP.md, CLAUDE.md | Figma MCP 연결, 이름 매핑 규칙 |
| figma/plugin/ (npm run figma:plugin) | 토큰을 Figma Variables 로 올리기 |
| figma/code-connect/ds-button.figma.ts | Code Connect |
| src/react/index.ts, examples/ | React·Vue 에서 쓰기 |
