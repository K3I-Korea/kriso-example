# 1강 Figma × Lit 디자인 시스템 연동 — 실습 자료

슬라이드: 「1강 Figma × Lit 디자인 시스템 연동」
2강과 같은 프로젝트(k3i-ds)입니다. 따라 하기 교재는 k3i-ds/study/ 에 00~07장으로 있습니다.

## 실행
```bash
cd k3i-ds
npm install
npm run dev        # 토큰 빌드 → http://localhost:5173  ← 1강 실습 화면
```

## 이번 시간에 쓰는 파일
| 파일 | 슬라이드 |
|---|---|
| tokens/tokens.json, tokens/themes/dark.json | 토큰 — 디자인 값의 단일 공급원, 다크 테마 |
| scripts/build-tokens.mjs (npm run tokens) | Style Dictionary — JSON → CSS 변수 |
| src/components/ds-button.ts, ds-input.ts, ds-card.ts | Lit 컴포넌트, Shadow DOM |
| src/styles/shared.ts | 공통 스타일, 포커스 링 |
| index.html | 실습 1 — 데모 화면 |
| scripts/build-figma-plugin.mjs, figma/plugin/ (npm run figma:plugin) | 토큰 → Figma 변수 |
| figma/code-connect/ds-button.figma.ts, figma.config.json (npm run figma:connect) | Code Connect |
| examples/react/SignupForm.tsx, examples/vue/SignupForm.vue | 순수 HTML · React · Vue 에서 쓰기 |
| CLAUDE.md, figma/SETUP.md | Figma MCP 연결, 이름 맞추기 규칙 |
| figma/LESSONS.md 의 L1–L7 | Figma 실습 |
| study/00~07 | 따라 하기 교재 |
